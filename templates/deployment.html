🚀 Configuration & Multi-Computer Deployment Guide

OPERATIONAL MANUAL

Run the decentralized blockchain voting cluster either as a concurrent 3-node simulation on a single computer or deployed across physical laptops over a Wi-Fi / LAN switch.

💻 Deployment Mode A: Local 3-Node Simulation

Spins up three independent logical node processes on localhost with isolated SQLite databases and distinct ECDSA keypairs:

  • Node A (Leader): http://127.0.0.1:5001 (DB: data/node_a/node_a.db)
  • Node B (Validator): http://127.0.0.1:5002 (DB: data/node_b/node_b.db)
  • Node C (Validator): http://127.0.0.1:5003 (DB: data/node_c/node_c.db)
  • Voter Portal EVM: http://127.0.0.1:5050
# Start all 3 nodes simultaneously:
python3 main.py

# In second terminal, start the EVM UI:
python3 voting_ui.py --port 5050

🌐 Deployment Mode B: Physical LAN Across Laptops

Connect each physical laptop to the same Wi-Fi router or switch and bind to 0.0.0.0:

# On Laptop A (e.g. IP 192.168.1.10):
python3 app.py --node-id node_a --host 0.0.0.0 --port 5001 --peers http://192.168.1.11:5002 http://192.168.1.12:5003

# On Laptop B (e.g. IP 192.168.1.11):
python3 app.py --node-id node_b --host 0.0.0.0 --port 5002 --peers http://192.168.1.10:5001 http://192.168.1.12:5003

# On Laptop C (e.g. IP 192.168.1.12):
python3 app.py --node-id node_c --host 0.0.0.0 --port 5003 --peers http://192.168.1.10:5001 http://192.168.1.11:5002
⚠️ Ensure OS firewalls permit incoming TCP traffic on ports 5001, 5002, 5003, and 5050.
